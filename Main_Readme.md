## 📌 Project Overview

A mobile-first, SEO-friendly single-page website for **Heaffles Café & Fast Food**, University Town, Peshawar. The site showcases deals, soups, full menu, gallery, reviews, and location details, with direct **WhatsApp ordering**.

## ✨ Features

- Responsive hero section with rating, opening hours, and CTAs
- Deal cards for solo, family, and group orders
- Soup feature section with video
- Gallery grid
- Searchable full menu
- Cart/order bar
- Customer reviews
- Visit/location section
- WhatsApp ordering integration
- Google Maps directions
- Local SEO structure

## 🛠 Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: Fraunces & Inter
- WhatsApp deep links
- Google Maps directions
- Base64 assets for demo
